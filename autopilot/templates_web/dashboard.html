請連接手機

請連接手機，在手機上完成 IG 發文／草稿。

  1. 用 USB 線接上 HTC U23 pro，解鎖螢幕。
  2. 確認「開發人員選項 → USB 偵錯」已開啟；跳出「允許 USB 偵錯？」時按允許。
  3. 接好後再按一次「存成 IG 草稿（手機）」。

會用這幾張圖卡（依序，第一張是封面）：

在手機上存成 IG 草稿？

手機已連線。程式會把下面四張圖推到手機（Pictures/VentureCrew），在 Instagram 開新貼文、選圖、貼上 IG 文案，最後存成草稿。不會按分享。

{% if ig_cards %}
    {% for img in ig_cards %}
  1. {{ img.name }}
    2. {% endfor %}
{% endif %}

貼中文文案時會短暫打開 scrcpy 視窗（約 5 秒）並自動按 Ctrl+V，請先別動滑鼠鍵盤。

轉發貼文到限動？

先確認貼文已經由你自己發佈。程式會打開那則貼文 → 紙飛機 → 「新增到限時動態」，貼文約佔 80% 寬、四周留底色，加上課前表單的連結貼圖（右上角）{% if ig_music[1].title %}和限動音樂「{{ ig_music[1].title }}」{% else %}（限動沒有設定音樂）{% endif %}。

不會按「限時動態／摯友／分享到」。這台 IG 沒有限動草稿，最後會停在編輯畫面，由你在手機上確認後自己分享。

貼網址和連結文字時會短暫打開 scrcpy 視窗並自動按 Ctrl+V，請先別動滑鼠鍵盤，也別碰手機。
