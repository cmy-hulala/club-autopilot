# Bundled fonts (SIL Open Font License 1.1)

Used only by the certificate fallback renderer (`autopilot/certificate.py`) to approximate the
fonts of the official Canva certificate (DAGzIgWU-E4):

- `GreatVibes-Regular.ttf` — Great Vibes by TypeSETit (OFL 1.1), stands in for Canva's "Aniyah" script.
- `Montserrat-VariableFont_wght.ttf` — Montserrat by Julieta Ulanovsky et al. (OFL 1.1), stands in for "Garet".

The Chinese name uses the system Noto Serif TC / Noto Serif CJK (Source Han Serif family, as in Canva).
